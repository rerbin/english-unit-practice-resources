# 英语单元练 UX Writing 文案规范

## 产品语气

- 对孩子：简短、鼓励、直接说明下一步。
- 对家长：准确说明结果、数据范围和不可逆后果。
- 不责备，不使用“你错了”；使用“需要练习”“再试一次”。
- 不泄漏实现词：校验、目录、清单、解压、私有目录、variant、异常路径。

## 统一术语

| 对象/动作 | 统一文案 |
|---|---|
| 当前课程音频 | 本单元语音 |
| 44 个内置音标音频 | 基础音标发音 |
| active | 正在练习 |
| mastered | 已掌握 |
| 添加错题 | 加入错题本 |
| archive | 移到“已掌握” |
| restore | 移回“正在练习” |
| delete mistake | 永久删除 |
| pronunciation/writing category | 练习类型：发音／拼写 |
| selected mistake words | 需要重点练习的单词 |

## 动作文案规则

- 按钮使用动词或动宾结构：下载语音、更新语音、听、拼、掌握、移出、重练、永久删除。
- 即时生效设置用“关闭”，不用暗示提交的“完成”。
- 普通弹窗退出用“取消”；页面级返回保留“返回”图标。
- 危险操作按钮必须写出后果：“永久删除”，禁止只写“确定”。

## 状态文案规则

- 先说当前状态，再给下一步：`本单元语音尚未下载` + `下载语音`。
- 成功说结果：`本单元语音已下载，可以离线使用。`
- 可恢复失败说恢复方法：`下载暂时中断。请检查网络后重试；已下载的部分会保留。`
- 文件损坏说清系统处理：`下载的语音文件不完整，已自动清除。请重新下载。`
- 不显示原始异常 `e.getMessage()`；详细原因只写日志。

## 反馈位置

- 学习页的下载状态：顶部状态行。
- 跨页面操作反馈（错题本、设置、导出、音色）：全局短暂提示条，使用 `aria-live=polite`。
- 当前弹窗的表单校验：弹窗内就地提示。
- 永久删除：专用危险确认弹窗。

## 标点与格式

- 完整提示句使用句号；按钮和标签不加句号。
- 中文栏目名统一使用中文引号：“正在练习”“已掌握”。
- 组合类型使用顿号：发音、拼写；不用 `+`。
- 不在主要提示中显示资源版本号、SHA 或内部 code。
- 百分比格式：`正在下载本单元语音：35%`。
