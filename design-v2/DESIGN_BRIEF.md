# 英语单元练 2.0 视觉与交互重构提案

## 目标

面向小学四年级学生与家长，以“准确、安静、易理解”为核心，采用 Material 3 Expressive 的方法重建设计系统，而不是机械复制 Android Compose 组件。

## 当前版核心问题

1. 颜色角色冲突：拼写标签与具体错词都使用粉红/红色，类别与错误位置无法快速区分。
2. 视觉 token 失控：CSS 中约 94 种颜色/渐变表达、46 处圆角、34 处阴影、52 处字号声明；局部合理但全局不统一。
3. 表达方式混杂：胶囊、渐变、左色条、Emoji、线性 SVG、文本符号同时存在。
4. 强调过多：顶部渐变、选中渐变、导出橙色、卡片左橙条、彩色操作按钮同时争夺注意力。
5. 标签和操作语义耦合：错误类型、具体错词、掌握状态、操作按钮没有严格分属不同视觉通道。
6. 旧版以阴影表达层级过多；长列表中每张卡都有明显阴影，造成视觉噪声。

## 2.0 设计原则

### 1. 表达服务于任务

M3 Expressive 使用颜色、形状、大小、动效和容器来引导注意，但不打破熟悉模式。关键操作更容易发现，普通信息保持安静。

本 App 的关键任务依次是：
1. 看清正在学习/出错的内容；
2. 听或练；
3. 标记掌握与整理；
4. 管理单元和设置。

### 2. 单一颜色角色

- Primary 蓝靛：导航、选中、播放、主要动作。
- Spelling 紫：拼写错误类别、拼写练习入口。
- Pronunciation 琥珀：发音错误类别。
- Error 红：只用于具体错误词、失败、不可逆删除。
- Success 绿：掌握、成功。
- Neutral：单元来源、说明、禁用。

禁止：拼写标签使用红色；普通卡片使用错误红；删除与移出共用同一图标/颜色。

### 3. 形状有语义，而非随机装饰

- 页面主容器：28px 大圆角。
- 内容卡片：24px。
- 控件与按钮：16px。
- 标签：12px 或全圆角。
- 选中状态可以更饱满，但同类组件必须共享形状规则。

### 4. 层级优先靠色面和间距，少用阴影

- 页面背景、卡片表面、选中容器形成三级色面。
- 阴影只用于浮层、底部导航和临时抬升对象。
- 列表卡片采用 1px outline 或轻微色差，不给每张卡重阴影。

### 5. 动效克制

- 导航、筛选、切单元：瞬间或短淡入，不做持续滚动。
- 连读焦点：保留必要的平滑跟随。
- 按压：90–140ms 轻缩放/色变。
- 弹层：200–300ms 强调 easing。
- 尊重 prefers-reduced-motion；减少动效时关闭平滑滚动和缩放。

### 6. 可访问性

- 主要触控目标至少 48px；密集行内操作不得低于 44px。
- 文字与背景满足至少 4.5:1（大字可 3:1）。
- 不依赖颜色独立表达：类别有文字，错误词有下划线/字重，选中有容器与图标。
- 图标配文字；全局导航用同一套 SVG。
- 适配系统字体放大，不固定卡片高度。

## 关键页面方案

### 学习页

- 顶部单元选择成为一张大号主容器，左右切换作为次要图标按钮。
- 连读用一个主按钮；停止只在连读时进入可操作态。
- 分区标题与内容卡分离，减少重复边框。
- 点读与记错题保留明确图标和文本辅助标签（宽屏）；手机可只显示图标但有 aria-label。

### 错题本

- 顶部单元范围保持上下文复用。
- 状态切换作为大号 segmented control。
- 类型 chips：全部=Primary，发音=琥珀，拼写=紫；未选中使用对应低饱和色，不再全灰。
- 具体错词仅使用 Error 红 + 下划线 + 很浅的错误底色。
- 卡片不使用统一橙色左边框；错误类别已经由 chip 表达。
- 四个操作统一图标体系；删除是唯一红色危险动作，移出为中性动作。

### 设置

- 保留底部 sheet，但去掉多余渐变和重阴影。
- 采用分组列表、清晰的标题与支持文字。
- 当前音色、离线状态是状态信息，不伪装成强操作。

### 导航

- 保留学习/错题本/设置三个入口。
- 统一 SVG、24px 图标容器、标签；选中项使用较宽 active indicator。
- 设置作为 modal destination 时仍不改变学习/错题本的内容状态，但其按钮按下有瞬时反馈。

## 迁移策略

1. 2.0 原型阶段：独立 HTML/CSS，无数据库和下载器改动。
2. 视觉 token 阶段：将颜色、字号、圆角、阴影、动效收敛为 CSS variables。
3. 组件阶段：重建 App bar、navigation、chips、cards、buttons、dialogs、sheet。
4. 页面阶段：先错题本，再学习页，再设置/说明/弹窗。
5. 行为回归：保留现有数据库、语音包、下载、错题、滚动位置和导出逻辑。
6. 发布：versionName 2.0.0；开发期自用可不做兼容迁移，但需保留同一包名和签名以覆盖安装。

## 验收指标

- 颜色语义无冲突；拼写 chip 与错误词至少在色相和明度上双重区分。
- 关键操作 2 秒内可定位；不出现三个以上同时高强调的控件。
- 390×844、412×915、平板 1024×768 无溢出。
- 字体缩放 1.3 倍不遮挡按钮。
- 减少动效模式下无平滑滚动和缩放。
- 所有交互状态：default/pressed/selected/disabled/error/success 可区分且不只靠颜色。
