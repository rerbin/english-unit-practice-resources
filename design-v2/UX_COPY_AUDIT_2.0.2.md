# 英语单元练 2.0.2 文案审计台账

## 审计范围

- 学习页、错题本、设置、单元选择、音色选择、使用说明。
- 加入错题本、拼写练习、删除本单元语音、永久删除错题弹窗。
- 下载、播放、导出、错题数据库操作的成功/失败/空状态。
- 导出文件名、表格标题、列名和单元名称。
- Android 原生提示与确认按钮。

## 主要改动

| 旧文案/问题 | 2.0.2 文案 | 理由 |
|---|---|---|
| 记入错题本 | 加入错题本 | 动作更自然，页面与按钮统一 |
| 错误类型（可多选） | 需要练习（可多选） | 对孩子更友好，不强调犯错 |
| 点选具体出错的单词 | 选择需要重点练习的单词 | 从责备式转为任务式 |
| 保存 | 加入错题本 | 按钮直接说明结果 |
| 全部类型 | 全部 | 上下文已明确为练习类型 |
| 已经掌握 | 已掌握 | 更短，全 App 统一 |
| 掌握状态已更新 | 已标记为“已掌握”。／已取消“已掌握”标记。 | 说明实际结果 |
| 已放入已经掌握 | 已移到“已掌握”。 | 与栏目名称一致 |
| 已放回正在练习 | 已移回“正在练习”，可以继续复习。 | 说明位置与下一步 |
| 移出前二次确认 | 取消确认；未掌握时提示先标记 | 操作可恢复，不需过度打断 |
| 导出 | 导出全部 | 明确导出不受当前筛选影响 |
| 错误类型／内容（英）／错误单词 | 练习类型／英语内容／需练单词 | 表格语言与页面一致 |
| 导出单元 ID | Starter／Unit 1 等教材名称 | 避免显示内部 ID |
| 导出表格无时间 | 表格标题下增加导出时间 | 打印后可识别 |
| 语音包未下载 | 本单元语音尚未下载。 | 统一对象术语 |
| 下载失败：原始异常 | 下载失败。请检查网络和存储空间后重试。 | 不泄漏技术错误，提供下一步 |
| 文件校验失败 | 下载的语音文件不完整，已自动清除。请重新下载。 | 说明系统处理和恢复动作 |
| 该内容暂无离线音频 | 这条内容还没有语音。请先下载或更新本单元语音。 | 给出下一步 |
| 本页暂无可连读内容 | 本页没有可以连读的内容。 | 更自然 |
| 完成（设置） | 关闭 | 设置即时生效，不需要提交 |
| 当前正式音色 | 当前音色 | 删除内部发布口吻 |
| 语音方案 | 音色 | 用户语言统一 |
| 删除单元语音普通确认 | 专用可恢复删除弹窗 | 明确可重下、保留教材/错题/记录/错题语音 |
| 永久删除普通确认 | 专用危险弹窗 | 明确永久、无法恢复和删除范围 |
| 操作反馈写在学习状态栏 | 全局短暂提示条 | 错题本和设置页也能看见 |
| 普通/错误提示时长相同 | 普通 2.8 秒；错误 4.2 秒 | 长错误信息有足够阅读时间 |
| 原生提示按钮“确定” | 知道了 | 普通提示更自然 |
| 原生确认按钮“确定” | 继续／取消 | 说明这是继续执行动作 |

## 统一术语

- 本单元语音
- 基础音标发音
- 正在练习
- 已掌握
- 加入错题本
- 移到“已掌握”
- 移回“正在练习”
- 永久删除
- 练习类型
- 需要重点练习的单词

## 文案显示规则

- 学习下载状态显示在顶部状态行。
- 跨页面操作结果使用全局提示条，`aria-live="polite"`。
- 表单校验在弹窗内就地显示。
- 可恢复删除和永久删除使用不同弹窗。
- 不直接显示 Java 异常消息；详细信息只写 Android 日志。
